# 中国强军与科教 1.0.0

这是普通 Unciv 扩展模组，使用游戏原生 JSON 规则，手机和电脑共用，不需要补丁、Root 或悬浮助手。

## 中国专属能力

1. 有军事学院的中国城市，新训练或用金币购买的军事单位，军事学院贡献的初始经验由原版 +15 提高到 +800。兵营、军械库、奇观、政策等其他经验仍按原版叠加。例如仅军事学院时为800，另有原版兵营和军械库时为830。不是战斗经验倍率，也不对既有军队补发800经验。无军事学院的中国城市、民用单位和其他文明不获得额外785经验。
2. 中国在研究科技进入一个新时代时，自动获得2个大科学家实体单位，按原版规则在城市附近可放置的位置生成。科研点数和科学家专员槽位不在这项修改范围内。同一时代继续研究不会重复发放，其他文明没有奖励。

本包通过“学院原有15 + 中国专属额外785”实现800，保留原建筑定义。因此学院百科的原始15经验说明可能仍然保留，额外785列在本模组全局规则中；实际新生成军事单位的经验已经按800计算，并非尚未生效。

从远古开局时，首次奖励在进入古典时代发放；初始时代不额外赠送，不追补过去时代。高级时代开局也不追补；新加入已有对局时，须在该对局实际启用模组后进入下一个时代才触发。一次跨越多个时代时，通用时代触发器按一次时代变化赠送2个，不按跳过的时代额外补发。原版可重复的未来科技不会无限刷科学家。

## 安装和启用

电脑：解压ZIP，将 China Military Science 整个文件夹放到Unciv的mods目录，重启游戏后在新建游戏的扩展模组列表勾选该模组，选择中国。已运行的游戏不会仅因安装文件就自动启用新模组；先用新局验证最稳妥。

手机和电脑均可在游戏“模组 → 从URL下载”中粘贴仓库地址：https://github.com/zjmnb66611/China-Military-Science 。只复制地址文字，不复制Markdown括号。安装后在新建游戏的扩展模组列表启用 China Military Science（中国强军与科教）。在线模组列表名称搜索可能需要等待索引更新，仓库URL安装不依赖列表搜索索引。

手动ZIP下载与版本说明：https://github.com/zjmnb66611/China-Military-Science/releases/tag/v1.0.0 。这是模组ZIP，不是APK；ZIP应解压后形成 China Military Science/jsons/GlobalUniques.json 等文件。

## 兼容设计

不包含Nations.json、Buildings.json、Techs.json、Eras.json或Units.json，不覆盖中国原有领袖、能力、特色单位、建筑和科技树，只追加两个带China条件的全局规则。内部文明标识必须仍是China；单独添加的中华人民共和国等其他文明标识不自动适用。

军事学院原版加成为15，本包只追加785，避免覆盖其他建筑模组。如果另一模组主动改变军事学院原有经验或移除Military Academy，学院贡献会相应变化，不能保证仍恰好800。中国军校替代建筑若被原版建筑过滤器识别为军事学院，按同样条件生效。

使用原版时代变化触发器，所以也适用于兼容模组实际定义并进入的后续时代。Continued和Worlds仍应分别搭配各自对应的华夏兼容版，不应把互斥的华夏版本一起启用。

## 验证边界

验证报告随交付文件提供：使用本机真实Unciv引擎在独立内存对局中检查经验和时代奖励，不读写用户存档。手机4.22.7的相关规则已对照官方该版本源代码；这不等同于在Magic7实机完成操作验证。
